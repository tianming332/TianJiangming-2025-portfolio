# TJM Material Lab — 模型库

页面入口：`index.html`。选择右侧「模型库」下拉菜单：

| ID | 模型 | 材质 |
| --- | --- | --- |
| 0 | Crimson 红瓤冻西瓜 | 原有西瓜果冻 |
| 1 | Golden 金瓤冻西瓜 | 原有西瓜果冻 |
| 2 | Rosé 粉瓤冻西瓜 | 原有西瓜果冻 |
| 3 | Jelly Pig 果冻小猪 | 粉色透射、背面厚度估计、Fresnel 高光 |
| 4 | Plush Pig 毛绒小猪 | 短绒、绒面漫反射、腹部及脚掌缝线 |

## 实现

- 小猪由超椭球曲面和管状网格构成：头、身体、耳朵、鼻子、鼻孔、眼睛、腮红、四肢和卷尾。
- 两种小猪材质共用缓存曲面。毛绒版本额外绘制 17,637 簇双面锥形短毛，不使用图片广告牌。
- 所有建模、材质和交互逻辑均在页面的 ES module 内；无需加载外部模型、贴图或第三方 3D 库。
- TJM 设置组件继续使用既有的本地 `tjm/` 文件。
- 小猪支持旋转、缩放、局部拖拽、回弹、Nudge、Pause、¼ speed、Reset 和真实网格查看。

## 范围说明

小猪使用弹簧形变 rig，而非四面体 XPBD；其质量、相对体积和能量读数为示意比例。
切换回西瓜后，仍使用既有四面体求解器。透明材质为实时光学近似，不是路径追踪。

## 调试与测试

可通过 `?model=3` 或 `?model=4` 指定首屏模型。

```js
__melon.selectModel(4);
__melon.modelInfo;       // 当前模型几何、部件和毛簇数量
__melon.topology;        // 当前模型使用的求解类型及网格统计
__melon.pauseRAF();
__melon.advance(0.5);
```

运行几何与切换回归测试：

```sh
node tests/model-library.test.mjs
```

测试覆盖五个选项、索引/法线有效性、缓存复用、拖拽释放、Nudge、稳定回落、确定性重置及西瓜状态保留。
